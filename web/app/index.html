How much to say

A new version is ready.
Install CleanJibe. It gets an icon, opens without browser chrome and works with no signal. It joins your share sheet too, so Share → CleanJibe on a .fit or .gpx opens the analysis.

Sessions

That shared file did not arrive. Share it again and pick CleanJibe.

How your sessions get in

  1. Drop a .fit, .gpx or .tcx here

    Or choose a file. It never leaves this tab.

  2. 10 real minutes on Lake Garda, already analysed.

  3. Garmin with the CleanJibe watch app

    Paste your intervals.icu key in Settings. Sessions arrive by themselves.

  4. The CleanJibe Apple Watch app

    On the iPhone app. A browser cannot reach your watch.

  5. Apple’s own Workout app

    On the iPhone app. Apple Health is closed to a browser.

  6. Any watch that writes a .fit

    Export the file. Then drop it here.

  7. Strava

    On the iPhone app. Strava sign-in needs it.

What you get

.fit, .gpx and .tcx all work. What each one can show differs.

Free, no account. Your file never leaves this browser tab. The analysis runs on your own device.

  1. Starting the analyzer
  2. Loading the analysis engine
  3. Reading the FIT file
  4. Analyzing

The engine downloads once, about 12 MB, then stays cached. The next file starts straight away.

A long session recorded with the accelerometer can take several minutes. The tab is working, not stuck.

That file could not be analyzed

Most often the file is not a FIT recording. Or it is a converted export rather than the original file from the watch. On intervals.icu or Garmin Connect, choose Download original file.

If the message below counts recordings, the .zip holds more than one. Unzip it and drop the single session you want.
