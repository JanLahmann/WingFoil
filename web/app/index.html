What you get

Garmin .fit files work: from the CleanJibe watch app, from Garmin's own Windsurf profile, or from another wingfoil Connect IQ app. A .zip of several is fine too. .gpx works as well — speed records are estimates there, and there's no pump data. Pump strokes and takeoff effort need the CleanJibe watch app; everything else works from any of them.

Free, no account. Your file never leaves this browser tab — the analysis runs on your own device.

intervals.icu optional

If your Garmin activities already sync to intervals.icu, pull a session straight from there instead of exporting it by hand. Your API key is stored only in this browser and is sent only to api.intervals.icu — never to this site's host, never anywhere else.

  1. Starting the analyzer
  2. Loading the analysis engine
  3. Reading the FIT file
  4. Analyzing

The engine (~12 MB) downloads once, then stays cached — the next file starts straight away.

A long session recorded with the accelerometer can take several minutes. The tab is working, not stuck.

That file could not be analyzed

Most often the file is not a FIT recording, or it is a converted export rather than the original file from the watch. On intervals.icu or Garmin Connect, choose Download original file.

Where this lives

    

      Saved sessions are written to this browser's private per-origin storage
      (OPFS, or IndexedDB where OPFS is unavailable). They are not synced, not backed up and
      not visible to any other site. Clearing this site's data, or using a private
      window, deletes them. Use Download all, or the per-row
      .fit / .json buttons, to keep a copy you own.
