Open beta · free · nothing to request

Get the beta

Both CleanJibe apps are free, open betas. The watch app installs from the Connect IQ store; the iPhone app installs from a public TestFlight link. There is no invite to apply for, no code to send in, and nobody to wait on.

Not sure you want either yet? The browser analyzer is not a beta at all — it reads a .fit file from any Garmin watch and gives you the whole session back. There is an example inside if you have no file to hand.

The Garmin watch app

Two steps, and neither of them is a mail to a person.

  1. Install it from the Connect IQ store

    CleanJibe Wingfoil Tracker (Beta) on apps.garmin.com — install it from the web store or from Connect IQ on your phone, the same way as any other watch app.

    Watches: the fenix 8 family (43 mm, 47 mm, Solar 47/51 mm, Pro 47 mm) and the fenix 7 family (7 / 7S / 7X and every Pro variant), with 0.9.4 widening that to thirty products — the epix 2 and Forerunner families, MARQ 2, Enduro 3, D2 and Descent Mk3 among them. If the store does not offer your watch the install button will say so.

  2. Ride

    Open CleanJibe on the watch and start. It records as a Windsurf activity — so it lands in Garmin Connect as what it is rather than as a walk — and it works out the wind direction for itself after a few minutes of riding.

One transitional note. The build on the store right now is still the invite one: it opens on a lock screen showing an 8-character request code, and needs a key entered in Garmin Connect → Connect IQ → CleanJibe → Settings → “Unlock key”. Version 0.9.4 drops the lock entirely and is waiting on Garmin's review. Until it clears, mail the code the watch shows to jan@lahmann-online.de and you get a key back — and if you already have one, keep it: existing keys go on working, on that watch, through every update.

There is a second Connect IQ listing, CleanJibe Field: a data field that adds the live foil numbers to Garmin's own Windsurf profile, for riders who would rather keep the native activity. It is on the same release train, so the note above applies to it too — and it has its own key, which the watch app's will not open.

The iPhone app

TestFlight, on a public link. Open it on the phone and you are in.

  1. Open the TestFlight link

    testflight.apple.com/join/nygqGGcn — on the iPhone itself. No address to submit and no invite mail to wait for.

  2. Install and open

    You need Apple's TestFlight app from the App Store if you do not have it; the link installs CleanJibe through it. TestFlight builds expire, so it will ask you to update every so often.

  3. Open the example first

    The app ships with a real session already in it, so you can see the whole thing — map, turn list, replay, records — before importing anything of your own. After that: connect intervals.icu in Settings, or share a .fit file into the app from Files or Mail.

The iPhone app does not need the watch app. It reads Garmin's own Windsurf recordings too; only pump strokes and takeoff effort need CleanJibe on the wrist, because only it records the wrist accelerometer.

It’s a beta — tell us what’s wrong and what’s missing

Every report lands with the one developer. A rough sentence beats a polished bug report you never send, and “this number looks wrong” is a perfectly good one.

Mail

jan@lahmann-online.de — the fastest door. What you rode, what the app said, and what you expected it to say. If a session was read wrong, attach the .fit file: with the file the detection can be re-run and fixed, without it there is only guesswork.

GitHub issues

github.com/JanLahmann/WingFoil/issues — better for anything with a screenshot, a file or a discussion in it, and it stays visible instead of ending up in one inbox.

What is most useful

Turns scored wrong, flights the watch missed or invented, a wind direction that disagrees with the day, and anything that stopped, froze or drained the battery. Which watch and which app version, if you have them to hand.

If neither is for you

The analyzer needs nothing

cleanjibe.org/app is free, has no account and is not a beta. Drop in a .fit file from any Garmin watch and you get the session back: foil time, every flight, the verdict on every turn, and your speed records. The file never leaves the browser tab.

Android is fine

The analyzer is a web page, so it runs in a phone browser as well as on a desktop — library and trends included. There is no Android app because there is nothing for one to do that the page does not.

Questions before you install

Mail jan@lahmann-online.de, or read the code and the detection thresholds first: github.com/JanLahmann/WingFoil.
