Get the beta

Both CleanJibe apps are free invite-only betas. The Connect IQ store will let anyone install the watch app, but it starts locked and needs a key that is issued per watch; the iPhone app is on TestFlight, which needs your address on the tester list. Neither takes long, and neither costs anything.

Not sure you want either yet? The browser analyzer is not a beta and needs no invite — it reads a .fit file from any Garmin watch and gives you the whole session back. There is an example inside if you have no file to hand.

The Garmin watch app

Five steps, and the middle one is a mail to a person. The lock is per watch and permanent: once a key is entered it stays entered, including after an app update.

  1. Install it from the Connect IQ store

    CleanJibe Wingfoil Tracker — Invite Beta on apps.garmin.com. The store lets you install it without a key; it is the app itself that is locked, not the download.

    Watches: the fenix 8 family (43 mm, 47 mm, Solar 47/51 mm, Pro 47 mm) and the fenix 7 family (7 / 7S / 7X and every Pro variant). If your watch is not on that list the store will not offer the install.

  2. Start the app and note the request code

    Open CleanJibe on the watch. Instead of the start screen it shows an 8-character request code. The code is derived from that watch, so it is different on every watch and the key you get back only works on the one that asked.

  3. Send the code to the developer

    Mail it to jan@lahmann-online.de — or use Contact Developer on the store page, which arrives in the same place. A sentence about what you ride and where is welcome but not required. You get a personal unlock key back.

  4. Enter the key in Garmin Connect

    On your phone: Garmin Connect → Connect IQ → CleanJibe - Invite Beta → Settings → “Unlock key”. Paste the key and save; Connect pushes the setting to the watch the next time they sync.

    The app was called WingFoil - Invite Beta before 0.9.3. If an older invite mail or store description sends you looking for that name, it is the same app under the new one.

  5. Ride

    The app unlocks immediately and permanently on that watch — no restart, no reinstall. From then on it opens on the ordinary start screen and records as a Windsurf activity.

There is a second Connect IQ listing, CleanJibe Field — Invite Beta: a data field that adds the live foil numbers to Garmin's own Windsurf profile, for riders who would rather keep the native activity. It is locked the same way and has its own request code and its own key — the watch app's key will not open it.

The iPhone app

CleanJibe for iPhone is in TestFlight. There is no public link: Apple sends the invite to a named address, so the address has to be on the list first.

  1. Mail for an invite

    jan@lahmann-online.de, with the Apple ID address you want the invite sent to. It is free and there is no limit worth worrying about.

  2. Accept it in TestFlight

    Apple mails you a link. Install Apple's TestFlight app from the App Store if you do not have it, open the link on the phone, and CleanJibe installs from there. TestFlight builds expire, so it will ask you to update every so often.

  3. Open the example first

    The app ships with a real session already in it, so you can see the whole thing — map, turn list, replay, records — before importing anything of your own. After that: connect intervals.icu in Settings, or share a .fit file into the app from Files or Mail.

The iPhone app does not need the watch app. It reads Garmin's own Windsurf recordings too; only pump strokes and takeoff effort need CleanJibe on the wrist, because only it records the wrist accelerometer.

If neither is for you

The analyzer needs no invite

cleanjibe.org/app is free, has no account and is not a beta. Drop in a .fit file from any Garmin watch and you get the session back: foil time, every flight, the verdict on every turn, and your speed records. The file never leaves the browser tab.

Android is fine

The analyzer is a web page, so it runs in a phone browser as well as on a desktop — library and trends included. There is no Android app because there is nothing for one to do that the page does not.

Questions before you commit

Mail jan@lahmann-online.de, or read the code and the detection thresholds first: github.com/JanLahmann/WingFoil.
